# Regions Unexplored: Terrain Diffusion compatibility

This repository contains a Fabric 1.21.1 compatibility bridge for Regions Unexplored and Terrain Diffusion.

## Fabric 1.21.1

See [FABRIC_BUILD.md](FABRIC_BUILD.md) for the build command and current compatibility limitations. Build with Java 21 using `bash ./gradlew build`.

The Fabric branch is maintained separately at `compat/fabric-1.21.1`. The existing NeoForge branches are intentionally left unchanged.

**Note:** the provided Fabric Terrain Diffusion jar targets Minecraft 1.21.11, not 1.21.1. A matching 1.21.1 Terrain Diffusion build is needed for runtime testing.
